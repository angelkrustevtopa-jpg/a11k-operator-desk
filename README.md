# A11-K Real Estate Operator Desk

This repository contains the public static conversion landing page for the **A11-K Real Estate Operator Desk**. It provides a focused introduction to the operating model, a bounded-engagement approach, and an enquiry path through the approved mailbox.

The page is automatically deployed to GitHub Pages after each push to `main`. It intentionally does not make property pricing, investment, legal, or regulated-professional claims. The source remains a concise public landing page while the responsible legal entity, domain configuration, and operational policies are finalised.

## Deployment

The GitHub Actions workflow in `.github/workflows/deploy-pages.yml` publishes the repository root as a static site. Custom-domain configuration is deliberately deferred until a domain has been registered, ownership has been verified, and the appropriate DNS records can be applied.
